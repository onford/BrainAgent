自适应搜索的实际动作顺序是：固定参考 → 同频带保留采集参考 → 8–40 Hz 平均参考 → 4–40 Hz 平均参考 → 1–40 Hz 平均参考 → 提前结束。每轮 `decisions/*/request.json` 只含当时已完成的评价。首次模型答复 JSON 不完整，被拒绝并占用一次提案额度，未执行该提案。

一次性提案在任何参考分数出现前冻结顺序，后续未调用 LLM 重排。随机策略未调用 LLM。各策略独立执行数值任务；所有重合候选的分数一致。

自适应搜索未继续测试其他频带的原始参考组合，因而遗漏了另外两种策略找到的 `bp1-40-original`。这提示当前模型会从局部对比过早推断未尝试组合的表现；这里没有证明自适应搜索带来性能优势。
