## 审阅范围与修正

| 角度 | 问题及处理 | 验证方式 |
|---|---|---|
| 本地观测与重试 | 原扫描可能在读取过程中更新哈希而掩盖源文件变化；失败后的重新扫描可能与旧调研混用。改为读取前后比较同一哈希，远程调研前保存本地快照，重试先核验冻结源文件 | 读取中替换文件、调研失败后替换文件，均拒绝继续使用旧观测 |
| 调研目标覆盖 | 自由目标列表容易漏项或把官方论文的媒介误写为官网。模型 Schema 固定两项核对目标和四类用途 × paper/repo 八项目标，问题和检索词由 LLM 填写 | 真实模型失败及修复后的重试；错误媒介、缺少目标的合同测试 |
| 文献阅读范围 | 短的 PubMed/arXiv 摘要页可能被误当全文。按页面类型与正文标记识别摘要；上下文预览超过 24,000 字符时不接受全文阅读声明 | 摘要页、正文预览和引用来源测试；实际筛选记录核对 |
| 网页结构 | 文本提取曾丢失 HTML 有序列表编号，使实验 Run 顺序难以判断。保留顺序号、start/value 和显式起始的倒序编号，嵌套无序列表不消耗外层序号 | 实验步骤列表、嵌套列表和脚本隐藏内容的回归测试 |
| 证据与链接 | 引文、相关链接、期刊、被引与星标必须来自实际读取或关联工具条目，不能用模型生成值替代 | 实际运行记录保留被拒绝的判断及修订；引文逐字校验，链接与指标来源校验 |
| BIDS 输入 | 仅文件存在和哈希一致不能证明元数据正确。增加 EEG 必需字段、采样率、参考、通道数、通道顺序、类型和单位的语义检查 | 修改元数据后重新计算哈希，仍由语义校验拒绝 |
| 事件边界 | 上下文事件也必须满足非负时间、有效时长和记录边界；接入保留所有 T0/T1/T2，训练只选择明确目标事件 | 非法上下文时长测试；真实 EDF、标准事件和训练映射三方逐行核对 |
| 亚采样点标注 | S088 的 14.38 秒标注被转换库量化为 14.3828125 秒，导致精确比对失败。先验证导出的整数采样点、标签和时长正确，再在 BIDS 事件表保存 EDF 原始精确秒数；读取时单独记录量化误差 | 真实 128 Hz EDF 触发；非网格对齐标注的回归测试；重试后逐行比对 |
| 方案结构 | 无关步骤可能带错误模型引用。Schema 按操作固定 model_from、decision_from、fit_scope 的允许形式 | 错误引用测试和模型实际方案编译 |
| 任务身份 | 扩展验收中，LLM 曾将未知 Run→任务对应降为普通限制而放行。运行时 Schema 增加逐 Run 的 verified/unresolved/contradictory 判断和引文 ID；未核实时禁止 compatible=true，进入补充取证；通道数量等通用事实不能替代具体 Run 引文 | 模拟模型错误放行后修订、补充阅读、重新核对的集成测试；真实模型复验先返回三个 unresolved 并暂停接入 |
| 混合采样率 | S088、S100 实际为 128 Hz，其他所选记录为 160 Hz。启用已有连续 Raw 重采样单元，以 polyphase 抗混叠并同步事件；要求同一候选覆盖全体记录且最终采样网格一致 | 混合采样率真实数据；分支隔离、采样后 Nyquist、事件碰撞和直接 MNE 数值对照 |
| 资源规模 | 每个记录原先复制整个数据集。工作副本改为当前被试目录和根级元数据，磁盘预算按实际副本范围计算 | 两个被试的真实 BIDS 工作副本测试；完整源清单仍逐一校验 |
| 失败记录 | 复制或读取阶段的异常可能发生在记录异常捕获之外。现在首个算子前的失败也写入 failure.json | 复制前改变输入，验证零步骤失败记录 |
| 输出一致性 | FIF 可读且有限不足以证明事件、数组和统计一致。复核精确电压数组、FIF、事件映射、Delta、通道及采样率；摘要计数必须与逐记录结果一致 | 篡改后重新计算哈希，仍拒绝数组、事件或统计互相矛盾的结果 |
| 报告与使用 | 混合输入不能统一展示成适配器预期的 160 Hz。采集表改用本地逐记录观测；重采样步骤展示实际目标率和事件同步方式 | 浏览器与结构化产物核对；输出数组和训练示例验证 |
| 报告执行顺序 | 复验报告的自由解释曾把统一重采样概括为所有候选“首先”重采样，与选中方案先滤波矛盾。报告 JSON 投影及 HTML 的执行顺序改由冻结方法生成；原始模型解释保留作审计 | 注入错误顺序文字的回归测试；最终报告、交付内报告和 ZIP 重新生成及校验 |
| 历史兼容 | 较早的完成记录没有 artifact_root，新增校验曾使列表返回 500。保持历史可选字段兼容，同时对新的计数、数组和事件关系进行严格校验 | 61 份历史阶段记录验证及运行列表 API、浏览器检查 |

## 能力边界

当前启用 9 类单元、10 个操作，真实执行由锁定版本的 MNE 数值代码完成，LLM 负责资料调研、接入判断及候选步骤、参数和依据。连续 Raw 重采样已集成；完整 RELAX、ICA、ASR、其他重采样变体、BIDS-iEEG 和 NWB 尚不属于已验证能力。没有执行完整官方 BIDS validator，也没有把一次数值跑通解释为模型效果或信号质量提升。

来源缺失、访问失败和未通过筛选的类别会保留为调研缺口；没有通过数据集身份与原文证据核对的资料不能补作权威依据。异常候选保留失败记录，只从覆盖全部保留记录且产物完整的候选中随机选择。

历史运行维持其原格式和产物。本轮结构仍采用格式版本 4；新增执行行为由冻结的执行计划、代码哈希和逐步参数标识。
