# 如何阅读预处理评价

候选由三个固定模型的训练效用选择；其他指标用于解释收益、发现副作用和规划下一次探索。先看被试与试次覆盖，再看分数，最后结合信号和重建证据判断机制。开发分数被反复用于探索，不是独立测试成绩。

## 训练效用与模型对照

每个外折按被试划分。同一被试的所有记录留在同一折，分类器、特征选择和内层调参只使用训练被试。每个模型先计算每位被试的 BA，再对被试等权平均。

`selection_score = (CSP-LDA 的被试平均 BA + FBCSP 的被试平均 BA + TS-LR 的被试平均 BA) / 3`。

三种主模型必须全部完成冻结范围的预测，否则没有选择分数。FgMDM、逐频带 EA-FBCSP、对数方差逻辑回归是另外三种固定对照，不临时替换主模型。每种模型另报被试分布的均值、标准差和低四分位数；低四分位数有助于发现平均成绩掩盖的低表现人群，不能据此删除被试。

| 指标 | 含义 | 阅读方法 |
| --- | --- | --- |
| BA | 二分类两类召回率的平均 | 两类权重相等；用于当前主分数 |
| accuracy | 预测正确的试次比例 | 受类别数量比例影响；不能无条件与 BA 混比 |
| F1 | 精确率与召回率的调和平均 | 当前以右手类为正类计算二分类 F1，再对被试汇总 |
| kappa | 扣除类别边际分布所对应机会一致性的成绩 | 不等同于简单的 accuracy 减 50% |
| AUC | 连续判别分数区分两类的排序能力 | 没有可用连续分数时不计算；硬标签不能冒充连续分数 |
| Brier、log loss | 预测概率与实际类别之间的误差 | 越低越好；只有真实概率输出才计算 |

EA 允许读取目标被试的整批无标签数据，属于离线转导。涉及这种适配的成绩必须与同等目标数据权限的结果比较。

## 信号质量：25 个固定指标

每个指标保存数值、单位、公式、适用状态、原因、分母和测量阶段。物理电压在 EA 之前测量；EA 输出的无量纲坐标不沿用电极电压阈值。连续片段与任务窗口分开计算，不拼接不连续试次来满足时长要求。

| 组别 | 字段 | 说明 |
| --- | --- | --- |
| 幅度与波动 | `peak_to_peak`、`robust_dispersion` | 峰峰值和稳健离散程度；幅度大不自动等于伪迹 |
| 空间相关 | `channel_correlation`、`low_correlation_fraction` | 每通道与其他通道绝对相关系数的高分位值，以及低相关窗口比例；相关过高也可能来自共同伪迹 |
| 阈值曲线 | `oha`、`thv`、`chv` | 分别统计高绝对幅度、跨通道标准差、通道时间标准差超过一组 µV 阈值的比例；阈值是描述性工程设定 |
| 平直信号 | `flat_fraction` | 连续至少 5 秒近乎不变的样本比例；2 秒任务窗本身不足以测量 |
| 数值结构 | `numerical_rank`、`covariance_condition`、`covariance_trace`、`participation_rank` | 秩、协方差条件数、总方差和有效维度；用于识别退化和结构变化，不能一律按高低排序 |
| 频谱 | `psd`、`psd_window_quantiles`、`mu_mean_psd`、`beta_mean_psd` | 功率谱、完整 4 秒窗口频谱分位数、8–12 Hz 与 13–30 Hz 的平均谱密度 |
| 高频与工频 | `emg_hf_proxy`、`line_ratio_50hz`、`line_ratio_60hz` | 高频功率比例和目标工频相对两侧频带的比例；是残余观察，不是伪迹真值 |
| 慢漂移 | `drift_slope`、`drift_power_ratio` | 至少 30 秒连续信号的线性斜率与低频功率比例；需要相应可用带宽 |
| 电极关系 | `electrical_distance` | 电极对差分信号的方差，同时保留几何距离；不单凭该数值诊断桥接 |
| 处理变化 | `reference_nrmse` | 与配对处理前信号的归一化变化；变化小不等于清理有效 |
| 任务响应 | `erds_mu`、`erds_beta` | 同样处理的任务段相对真实任务前基线的频带功率变化百分比；负值为 ERD，正值为 ERS |

已经被高通、低通或陷波去掉的频率不能重新作为完整频带证据。真实基线缺失、任务重叠、时长不足、奇异协方差等情况保留原因；`null`、部分可用和不适用均不作为零值参与比较。

## 半合成重建：污染去除与信号保留

设实际 EEG 参考为 `x`，已知注入污染为 `a`，候选处理为 `P`。分别运行 `P(x)` 和 `P(x+a)`；涉及自动拟合的步骤分别按各自输入重新拟合。比较前统一物理单位、通道、参考和测量频带，再按同一事件切窗。`x` 是实际 EEG 代理参考，并非纯净神经信号。

| 问题 | 主要字段 | 比较对象 |
| --- | --- | --- |
| 注入强度是否一致 | `input_nrmse` | `a` 相对 `x` 的 RMS |
| 注入污染留下多少影响 | `paired_nrmse`、`paired_error_cleanproxy_ratio`、`artifact_residual_rms_ratio` | `P(x+a) − P(x)`，分别以处理后参考、原参考或注入污染归一化 |
| 残余是否沿原污染方向 | `artifact_residual_coefficient` | 残余对已知污染的投影系数 |
| 与原参考的整体差距 | `reconstruction_nrmse` | `P(x+a) − x` 相对 `x` 的误差 |
| 去除改善量 | `paired_ser_improvement_db`、`reconstruction_ser_improvement_db` | 处理前污染 RMS 与相应处理后误差 RMS 的比值，以 dB 表示 |
| 波形相关 | `paired_correlation`、`reconstruction_correlation` | 处理后污染信号分别与 `P(x)`、`x` 的相关 |
| 未注入时改变了多少 | `clean_retention_nrmse`、`clean_retention_rms_ratio`、`clean_retention_correlation`、`clean_retention_gain` | `P(x)` 相对 `x` 的误差、幅度、相关和增益 |

恒等处理、零输出、整体收缩是固定对照。零输出可能没有污染残余，却损失全部信号；整体收缩可能改善某些误差却没有选择性去噪。因此必须联合阅读两类证据，不能只按一项重建指标选择方法。

默认探针覆盖全部被试，每人固定第一条任务记录及其中全部合格试次。眼动样污染、肌电样污染、漂移、工频和脉冲各设两档强度，十个条件按与成绩无关的规则均衡分配。全部候选复用同一分配；分类评价仍使用全部任务记录。`full_factorial` 可对每位被试运行十个条件，属于另行声明的追加评价。

## 从概要追溯证据

运行页的“多维评价”展示分数、覆盖和适用原因，原始明细在候选的 `assessment/aN/`。`operator-usage/uN.json` 给出每个算子实际应用、条件不适用、失败或尚未执行的记录数及文件证据。方法标题中有 ASR，不表示每条记录都执行了 ASR。

每项完整评价与输入、配方、数值计划、执行结果、评价面板及探针面板绑定，并保存文件哈希。下载训练包时一并提供模型预测、拟合模型与评价索引，可重算分数。科学来源及未接入指标的研究范围分别保存在运行冻结的 `scientific-knowledge.json` 和 `evaluation-evidence.json`。
