## 保留且应明确标识的正式约束

1. 8–30 Hz/平均参考、1–40 Hz/平均参考、采集参考是标准工程对照，不是论文最优方案，也不是本轮发现。
2. 固定共同 trial、通道、时间及采样网格用于可比较性；不能为纳入论文方案偷偷删除试次或改变任务标签。
3. EEGNet 三种子 17/42/2026、最多 100 epoch、patience=15 保持原协议。分类效用、物理电压质量、合成污染重建分别解释，不互相代替。
4. random/exhaustive/one_shot 是显式实验对照策略；其有限网格不代表连续空间穷举，也不代表正式 adaptive 策略。控制设计的固定分位数仅属于该对照。
5. JSON 修订次数、网络超时和读取大小上限是资源约束，不是“方法已充分调研”的证明。默认预算仍需要目标数据规模与实测成本校准。
6. 独立预处理 `PlanRequest.max_candidates=3` 是调用者可显式覆盖的编译批次预算；`selection=all` 超预算直接报错，不裁剪后冒充全部执行。它不应被当成正式搜索的候选预算或最终选优。`unit_graph_space` 的有限参数网格是工程 sweep，尚未代替当前文献驱动 adaptive 主循环。
