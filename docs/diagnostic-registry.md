# 可执行诊断注册与决策响应

新搜索冻结 `diagnostic-registry.json`、其哈希和实现源码哈希。每项注册包含输入域、允许阶段、标签权限、数值合同、可预测标量路径、是否需要参考候选和输出产物。新增内核须通过受信任代码注册和测试；模型只能选择已冻结的条目，不能提交执行代码。历史搜索不能回填新注册诊断。

当前三项为信号画像、物理合同一致的候选配对比较、保存 PSD 的频谱分布。频谱诊断计算实际保存频率网格上的首个最大值频点、PSD 最大值及梯形积分；不插值峰、不推断神经来源、不拟合个体变换。PSD 的非频率轴归约方式随测量保留。

执行前，模型登记竞争假设、一个已注册标量路径、数值比较、阈值及其理由，以及条件成立、不成立、不可用三个结果分支。缺失、部分覆盖、非有限值和不兼容测量进入不可用分支。数值条件只检查预测，不能证明机制。

执行后保存实际观测和选中的下一动作。下一次模型决定必须引用待响应的诊断；遵循分支时检查动作类型，修订时必须说明理由。前端同时展示预登记动作和实际模型决定。这个检查不保证自由文本理由在科学上正确，也不表示提出的后续实验已经执行。

预算与输入边界：

- 每次最多 64 MiB 输入、4096 个文件、4 MiB 输出，最多 60 秒；时间检查发生在有界读取和计算之间，是协作式上限，不是操作系统强制终止。
- 搜索默认最多 32 次诊断，累计输入预留 512 MiB，可在 SearchBudget 中显式配置。次数和字节共同限制调用，不能假设次数额度全部可用。
- 执行前持久化整次输入预留；失败和进程中断不退还不确定的预留。另记实际观察到的输入字节及耗时。重新措辞或改变阈值不会制造新的测量身份。
- 输入先检查大小，再读取并对实际解析字节验签。频谱和配对内核不读取无关的波形/时频明细。新质量回执包含缺测索引，画像可直接追溯原记录、指标位置和源明细哈希；历史回执没有索引时仍需读取原明细，超限则拒绝。
