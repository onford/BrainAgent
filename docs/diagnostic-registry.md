# 只读诊断与测量

2026-09-13 起，诊断内核只提供测量和解释证据。模型自主请求诊断、登记结果分支、响应诊断并改写预处理流程的逻辑已移除。当前边界见[首次推荐与固定执行](fixed-initial-recommendation.md)。

保留信号画像、具有一致物理合同的配对比较、保存 PSD 的频谱描述、共同视图变化、周期与非周期频谱及传感器差值等受信任内核。它们按原始单位、阶段、覆盖分母、缺失原因和文件哈希返回观测，不产生下一动作。带旧 experiment 分支的请求会被拒绝。

读取仍受输入字节、文件数与时间限制，先核对大小，再对实际解析的字节验签。部分覆盖、非有限数值和不兼容测量保留不可用状态；不能把缺测解释为没有污染或神经保护成立。

旧版的动态诊断响应实测保存在历史提交及 docs/sources/remaining-modifications-20260912/diagnostic-registry-live-*.json，不作为新版自主调整能力或验收目标。新版回归状态见[清理说明](fixed-initial-recommendation.md)。
