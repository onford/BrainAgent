# 研究知识修订

每个用户的知识目录有独立、持久化的修订链。第一次读取也保存第 0 版。新搜索冻结完整目录与修订摘要，普通预处理计划保存同一份知识；搜索子进程只使用搜索冻结版本。旧测量、旧计划和旧报告保持原样。

当前提供以下已登录接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/searches/knowledge` | 读取当前修订 |
| `GET /api/searches/knowledge/revisions/{sha256}` | 读取自己的历史修订 |
| `POST /api/searches/knowledge` | 原子更新来源或研究规则 |
| `POST /api/searches/knowledge/rebase` | 显式合并升级后的内置目录 |
| `GET /api/searches/knowledge/impact` | 只读比较历史搜索与当前目录，列出需重评范围 |

更新提交 `expected_sha256` 和逐项变更，包含对象类型、标识、状态、理由、带时区的观察时间及完整 Evidence（网址、版本、定位、原文）。可附完整 replacement 修正原对象，不能改动其标识。并发更新若使用过期摘要会拒绝，用户需先审阅当前版本；不自动覆盖另一项修订。

`active` 仅表示目录启用，并不表示刚刚独立核实了现实世界中的来源状态。`suspended`、`withdrawn` 来源使依赖规则失效，受影响研究派生算子或参数域阻塞、方法起点移除、软先验撤回；有独立实现或数学依据的硬约束保留。神经建议同时检查研究规则关联和目录中明确相同的网址。

修改来源或规则正文后，`binding_review_required` 会保留阻塞，即使状态改回 active。旧执行绑定不能由改写的文字自动认证。对应执行目录升级并经显式 rebase 核对后才能解除；内置目录变更时不会静默迁移用户状态。修改来源网址时保留原网址用于阻塞旧方法。这里只匹配明确的目录网址，不推断 DOI、出版社镜像或未登记别名等价。

新普通预处理的计划、提交、重试、发布检查当前知识。已冻结搜索中的候选继续使用其冻结知识，计划与搜索的摘要必须一致。影响报告列出受影响来源、规则、参数和算子关系；无法验签的历史依据单独标为不可核验，不猜测影响。重评需要新运行，不能修改历史回执。

本次回归使用明确标识的合成状态变更，没有实际撤回任何文献。实现覆盖修订与执行联动；自动发现现实世界的勘误/撤稿、全部知识的独立科学复核和图形编辑界面仍未完成。
