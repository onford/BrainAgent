# 评估图表勾选对比

图表标题栏提供“勾选对比”。切换候选、阶段、记录、指标或诊断通道后，可以继续添加图表；右下角“图表对比”入口跳转至集中展示区。选择按运行隔离，在当前页面会话中保留，刷新页面清空；最多保留 12 张，可以逐张移除或清空。

覆盖信号质量曲线、逐被试/试次/通道图、记录热图、电极对矩阵，以及训练种子/被试表现、重建条件、ROI 时频、波形、包络与电极位置。只展示有有效观测的图表入口。选择热图会保留整张矩阵，包含全部分页数据。

比较按指标和图表含义分组，种子分布与被试分布分开；组名显示所选效用/重建指标。每张图显示候选 ID、阶段、记录、通道和评估路径，并可展开完整来源。比较区保留原有 SVG / JSON 导出。

实现约束：

- 勾选时复制数据与来源，后续切换不会修改已选图表。无模型调用，无后端重算。
- 连续曲线共用覆盖全部已选图的横纵坐标范围，不插值、不求差、不填零。
- 分类图按标签对齐，例如同一重建条件在不同候选中顺序不同，不按数组位置配对。
- 热图共用色标，发散色标保持对称。各图保留各自的行列标签和采样网格，不将不同记录的试次强行配对。
- 诊断图按实际测量类型标识，不随质量指标下拉框变化重复加入。
- 并排展示用于整体观察，“放大查看”用于阅读细节；窄屏改为纵向排列并保留图内水平滚动。布局不改变图形导出的数值、尺度和来源。

验证：`FigureComparison.test.ts` 覆盖快照隔离、数量限制、分类对齐、热图子集与缺失值、共享色标、候选重挂载、指标分组及移除同步。真实实例浏览器测试使用两个候选和 S001R04 / S002R04，检查 PSD、C3/C4 时频、跨记录/阶段热图、训练种子及重建条件，并检查刷新行为、时间稳定性与移动端规格一致性。
