## 稳定性定义

相同输入、绘图配置、代码、字体和渲染环境应得到相同图形。等待、刷新、记录切换后返回、热图翻页后返回不改变数据、范围、颜色或导出内容。不同真实输入可以有不同结果；不通过平滑、丢弃极端值、填补缺失或固定随机伪数据制造稳定。

- 坐标由完整输入和确定性 1/2/2.5/5/10 刻度规则计算，不读取时钟或视口。缺失端点保留横轴位置；分类散点显示被试/种子标识并留出半格边距。
- 系列使用稳定 ID 分配 Okabe–Ito 颜色、线型、形状，顺序变化不换色。密集曲线保留全部点但不逐点绘制装饰标记；不减少路径采样。
- 普通明细热图固定每页 24 行、64 列，末页保留空位。TFR、窗 PSD 和通道对矩阵采用完整矩阵视图，保留全轴与全部单元，仅减少可见标签。色限来自完整数据。
- ROI 时频图使用同一记录和阶段的全部 ROI 通道、频率和时间共同确定对称色限，低频在下。负值为蓝、正值为红；零与缺失采用不同颜色。不同记录/阶段仍分别标注色限，不暗示共同参考和带宽。
- 原采样波形预览共用当前记录、阶段的全部预览通道幅度范围。阈值与低比例曲线从零开始，按完整当前数据确定上界，使低占比仍可读；相关系数图保留 0–1。
- SVG 不使用动画；字体、轴、色条、标题、图例都在 SVG 内声明。导出移除 Vue 注释与作用域属性，并按确定顺序保存样式，不依赖外层页面样式。

不保证不同浏览器、字体版本、操作系统之间逐像素相同，也不保证今后改变数据或代码仍得到相同图形。论文提交应固定 JSON、导出脚本、依赖和字体；PDF 嵌入字体，输出 manifest 保存这些文件的哈希。

## 科研表达与视觉规则

线图使用轻网格、明确单位、规则刻度和带形状/线型冗余的图例；不添加未经计算的置信区间。PSD 继续在线性功率域按原合同聚合后转 dB。窗级 Q10/Q50/Q90 不标为置信带。连续路径遇到缺失时断开；表格和 JSON 保留原精度。

顺序热图采用固定 256 色 viridis；有符号热图采用 RdBu_r，带数值色条及缺失图例。色表保存在 `frontend/src/utils/figurePalettes.json`，由 Matplotlib 采样生成，浏览器与科研导出共用同一表。不采用彩虹色图，不对图像做后期平滑或重新着色。

本次参考：

- [Nature figure guide](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)：89/183 mm 栏宽、最高 170 mm、5–7 pt 文字、标准字体与嵌入字体、可编辑矢量文件、色觉可访问性。
- [Proceedings of the IEEE 图表指南](https://proceedingsoftheieee.ieee.org/resources/guidelines-for-figures-and-tables/)：统一字体/标签风格、清晰可辨的最终尺寸、矢量图优先和按内容区分的栅格分辨率。

浏览器阅读版使用较大字体；Matplotlib 提供通用双栏、Nature 单/双栏及 IEEE 双栏配置。它们是参考规范的排版预设，不代表期刊对科学内容或最终投稿文件的认可。PNG 为 600 dpi 预览/栅格副本，Nature 主图优先使用矢量 PDF；不同期刊和 Extended Data 的要求需分别核对。

## 导出和复现

页面“下载图形 SVG”提供 183 mm 宽的独立矢量图；图中的标题、图例、色条随图保存，完整图注放在 `<desc>`，绘图合同放在 `<metadata>`。JSON 下载包含原数值、坐标、色限、系列样式、页索引、分母/来源；热图 JSON 保存完整矩阵。

从项目根目录，使用安装了 EEG 依赖（含 Matplotlib）的 Python：

```powershell
backend/.venv-eeg/Scripts/python.exe -X utf8 backend/scripts/export_assessment_figure.py figure.json --output figures/figure --profile nature-double
```

脚本生成 PDF、可编辑 SVG、600 dpi PNG、图注文本和校验清单。`nature-single` 使用 89 mm、6.5 pt；`nature-double` 使用 183 mm、6.5 pt；`research-double` 使用 183 mm、8 pt；`ieee-double` 使用 182 mm、8 pt。默认复现当前热图页；加 `--full-matrix` 可以导出完整矩阵并保留原色限。大矩阵可能超出单页尺寸或出现标签越界，脚本会明确失败，须另行选取适当页面/标签，不偷偷缩小字体。

PDF 嵌入 TrueType 字体；中文优先使用本机 Microsoft YaHei 或 Noto Sans CJK SC。无法覆盖文字时停止导出，避免缺字。JSON 原数值不修改；脚本不读取原 EEG、不重新评价。时间戳从矢量输出元数据中移除，记录输入、字体、调色板和导出器哈希。
