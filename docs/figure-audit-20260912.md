## 覆盖范围

浏览器遍历两个候选、汇总及各 12 条记录、全部 6 个阶段和 25 项质量指标，共 **3,900 个显示状态**。逐状态检查有限结果是否得到展示、坐标是否包含数值、矩阵是否与轴匹配，并核对 PSD 线性聚合后转 dB、阈值坐标、逐被试值、原始片段编号和通道对均值。另检查每条记录处理后任务阶段的三个 ROI 时频矩阵、完整时间轴和原始缺失掩码。

最终包含 2,072 次主图渲染、472 个单值或完全相同观测的摘要；1,404 个不可用状态不伪造图形。一种图可以在多个状态重复出现，这些计数不表示不同图种。

训练与重建另遍历 **42 个显示状态**，核对种子数据、所选重建指标、条件编号和缺失位置。视觉审查使用 27 张修复前图、修复后的 63 张信号图样本以及训练、重建和科研导出样张，覆盖所有当前图种；并非人工逐张观察全部重复状态的截图。

## 逐类判断与修改

| 图形 | 实测问题与用途判断 | 最终处理 |
| --- | --- | --- |
| PSD | 频谱及滤波后形状有诊断用途；实测数值与线性功率聚合后转 dB 一致。 | 保留原始频率网格，不平滑、不把零功率填作 0 dB。 |
| 窗 PSD 分位曲线 | 可观察窗间变化；短试次无法支持完整 4 秒窗。 | 保留可用曲线，缺测保留原因；不作为置信区间。 |
| 窗 PSD 热图 | 旧默认页只显示前 64 个频率格，容易遗漏完整谱形。 | 显示完整窗 × 频率矩阵；标签稀疏显示，数据不抽样。 |
| OHA／THV／CHV、低比例指标 | 固定 0–1 轴将约 1% 的差异压成贴轴直线。 | 比例轴从零开始，根据完整当前数据确定上界，正常范围上限不超过 1。不对有效值裁剪或置零。 |
| 逐被试标量 | 多被试差异有展示价值；完全相同值的分布图重复表格信息。 | 有差异则保留散点；全部可用观测精确相同时给出数值与观测数摘要。缺失值不参与“全部相同”的判断。 |
| 逐记录秩、条件数、总方差、参与率秩 | 原代码未处理一维片段数组，出现有测量但无展示。 | 按保存的原始片段编号绘制不连线散点；单值或完全相同时用摘要。保留不连续编号和缺失。 |
| 通道 × 窗口／片段热图 | 定位局部变化有价值；同时默认展示均值散点显得重复。 | 多行时以热图为主，通道均值按需打开；单行时只展示通道散点或常量摘要。标题包含具体指标。 |
| 电气距离 | 2,016 个通道对挤在序号散点中，难以定位；原矩阵需翻很多列页。 | 改为完整 64 × 64 电极对矩阵，按通道名称映射，取每对的有限片段均值。对称位置重复同一测量，对角线保持未测量。用途是定位通道对，不据此诊断桥接。 |
| ROI 时频 | 原默认时间页只有 64／81 列，隐藏末段及右侧边缘缺失。 | 全部 81 个时间格及 12 个频率格同时展示，保留两端缺失掩码，三个 ROI 共用完整数据的对称色限。 |
| 原采样波形 | 有助于检查短片段形态，已明确仅为首个有限片段。 | 保留，通道尺度一致。 |
| 全段 min／max 概览 | 长连续记录有必要；2 秒试次已由完整原波形覆盖，概览重复且易被误当原波形。 | 仅在记录超出原波形预览长度时显示；标题与来源记录通道。 |
| 电极布局 | 用于核对通道位置，不能作为信号质量图。原图太矮、ROI 无可见标签。 | 作为可展开的辅助图，增大纵向空间、保持等比例，并标出 C3／Cz／C4。 |
| 逐种子效用 | 三个种子的离散性有价值，不应当作置信区间。 | 保留固定种子位置和 BA 参考线。 |
| 逐被试模型效用 | 本例只有一个开发被试，两个模型的点可能重叠，并与表格重复。 | 只有至少两名有有限结果的被试时显示该图；本例以模型表格呈现。 |
| 重建污染残余 × 原信号改变 | 两个汇总轴可能来自不同有效被试集合，不宜画成貌似配对的关系；旧图也不随指标选择更新。 | 改为“所选指标 × 污染条件”的分类散点，保留未分配／缺失条件位置，随指标选择更新，不暗示相关性或配对推断。 |
