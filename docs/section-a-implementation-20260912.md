## 重建协议版本变化

重建评价版本由 `dataset-reconstruction-v3` 升至 `dataset-reconstruction-v4`。新协议先完成各方法的实际物理电压 epochs，再应用共同参考和比较频带；参考目标也先提取同一组冻结试次。这样源基线与评分投影可以被实际重放、核对。

所有新候选和新对照采用同一 v4 协议。历史 v3 产物未重写，也不能直接与 v4 数字混合比较。短窗口未覆盖注入扰动时保留 `NO_APPLICABLE_CONTAMINATION`，失败和不适用仍在固定分母中，不用零误差代替。
