# 排除提案的对象证据

当前接入只排除已确认的结构性失败。文献中的排除名单是来源声明，不能自动删除本地对象；开发分数不参与该决定。完整数据范围与训练任务范围分开记录，未把非目标 Run 当作质量失败。

文献提案必须保留原文对象片段与引用。纳入子集、留出人群、样本数量和不明确描述不能变成排除名单。被试编号仅从明确名单或有界范围解析；记录编号必须以完整、独立的 `S###R##` 出现在引用片段，不能从被试名单或运行数量推导。重复编号不能形成有效声明。通道和试次缺少已验证的记录上下文及编号体系时，保留为未确认。

未确认提案保留 `proposed`，同时将 `effective` 的编号清空；不形成有效的本地排除标记。来源文字和编号匹配仍不等于独立语义或科学验证，尤其不能仅凭论文讨论了本数据集，就假定其每一组编号都属于本地同一数据集。

18 项对象证据测试通过；包含产物可见性与进程树的组合批次 27 项通过（覆盖重叠）。对第 7 次真实调研保存的全部两条提案进行只读核对，引用片段均可在已保存来源正文定位：四个人群编号的删除声明仍有字面证据，在完整 1526 记录目录匹配 56 条记录，只保留标记；另一条包含样本计数的范围提案仍未确认，匹配 0 条。自动排除 0，历史文件不变，见 [真实对象核对](sources/remaining-modifications-20260912/exclusion-objects-live-1-audit.json)。

科学质量排除规则仍未完成：需要可定位来源、独立确认的数据集/记录/通道/试次对应、事前冻结的共同适用条件及排除前后统计。当前证据不授权新增科学阈值、按开发成绩筛除困难对象或恢复逐被试处理。全量 BIDS 接入的 109 人、1526 记录、4918 训练试次保持不变，但这只是现行保留政策的实测，并非科学筛除策略已验证。
