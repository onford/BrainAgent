## 已实现

- 训练效用：逐被试模型散点、EEGNet 逐种子散点；共享被试 ID 坐标，缺失断开，不自行补算 Q25 或置信区间。历史模型保留原协议。
- 信号质量：PSD、完整窗口 PSD 分位曲线、OHA/THV/CHV 阈值曲线、逐被试分布；按记录读取通道/窗口热图及通道分布。热图按行和列分页，所有页共用色限。
- 新评价另保存首个有限片段的原采样波形、全片段 min/max 概览和已有电极坐标。预览只选 C3/Cz/C4 中存在的通道，否则前三通道，明确不代表所有试次。历史缺少预览时不伪造，也不从原始 EEG 自动补算。
- 半合成重建展示污染残差与原信号改变的组级关系；不冒充同一案例的配对估计。
- SVG 和绘图 JSON 下载、精确数值表、原记录链接。图表标明阶段、单位、实际频率轴、缺失原因和汇总分母。
- 参数面板展示冻结配方顺序、参数允许域、单位、来源类型与依据 ID、拟合权限、任务网格、种子及训练配置。展示不编辑冻结运行，未记录项保留缺失。

## 审阅结论

以用户 [skill](https://github.com/liujiany22/eeg-preprocessing-reporter) 为需求参考，不能将其中所有参数视为已验证阈值。

| 项目 | 本次判断 |
| --- | --- |
| PSD | 在线性功率上按记录合同聚合，再转 dB；窗分位数不是置信带，记录分位曲线的均值不是合并窗分位数。分段长度与 FFT 网格分开解释。依据：[MNE Welch](https://mne.tools/1.10/generated/mne.time_frequency.psd_array_welch.html)。 |
| 相关阈值 0.4 | 只有连同窗口、低通与参考条件才有解释意义。PREP 原方法与本项目诊断不同，不能宣称复现 PREP。高相关也可能来自共同噪声或插值。依据：[PREP 原文](https://www.frontiersin.org/journals/neuroinformatics/articles/10.3389/fninf.2015.00016/full)。 |
| 平坦、超幅和高方差 | 工程诊断参数，不是通用坏数据判定。相邻差阈值受采样率影响；THV 是跨通道标准差超阈的时间比例，不是“试次高方差”。 |
| 工频、高频 | 只覆盖 50 Hz 不证明工频是 50 Hz。30–45 Hz 比值不是肌电真值。两人神经肌肉阻断研究支持肌电污染的可能性，不验证这个比值阈值：[Whitham 2007 摘要](https://pubmed.ncbi.nlm.nih.gov/17574912/)。 |
| ERDS | 当前是 Welch 频带基线归一化，不能称作完整时频图；基线须有真实事件支持并匹配处理阶段。参照而非声称复现：[MNE ERDS 示例](https://mne.tools/1.10/auto_examples/time_frequency/time_frequency_erds.html)。 |
| 空间与秩 | 电极位置散点不冒充插值地形图；标准模板不冒充个体测量。平均参考降低数值秩是预期代数结果，参与率秩另有含义。 |
| 频带功率 | 功率变化不必然是振荡变化，也可能来自非周期成分：[Donoghue 2020 摘要](https://pubmed.ncbi.nlm.nih.gov/33230329/)。 |

本次没有改变既有 25 项信号质量指标的计算/阈值或 EEGNet 选择规则，仅增加可审计诊断数据和解释。共同参考/共同带宽前后比较、完整 TFR、ICA/EOG/ECG、统计推断不在当前已实现范围中；缺少必要数据时保持明确缺失。

## Agent 如何使用

`backend/app/search/resources/interpretation-guide.json` 保存 11 张知识卡、8 个来源及研究缺口，覆盖当前 25 项信号指标，并包含效用与重建解释。每张卡记录适用条件、竞争解释、后续核查、禁止的推断、参数依据和原文定位；明确区分全文、官方文档、摘要和用户工程规范。

新搜索创建时保存 `interpretation-guide.json`、摘要来源及哈希；反馈上下文包含冻结知识卡，现有预算内 `request_evidence` 可读取完整知识与来源定位。顺序为：核对单位/阶段/分母 → 引用实测数值 → 列竞争解释 → 选择可区分解释的合法诊断 → 登记并核对预测。它提供解释先验，不替代数值计算或修改选择规则。

旧搜索没有冻结此知识时，agent 不获得当前知识的回填；页面可通过 `/api/searches/interpretation-guide` 阅读当前知识，但明确标记为历史运行之外的参考。新增文献须审阅原文定位、适用条件和反例后更新版本；本次没有开启自动联网常驻调研。

## 验证范围

数值测试核对原采样点、瞬态 min/max 保留、输入未改动、窗口 PSD 与原分位数完全一致以及短片段不伪造长窗。接口测试覆盖新运行知识冻结、哈希及所有权隔离；前端测试覆盖缺失断线、记录路径、竞态切换、读取重试、历史知识标识和热图分页。

真实历史搜索用于浏览器只读展示验收；不能据此宣称新协议全集实验通过。最初一项旧的两被试子进程测试期待历史 CSP 成功，与新 EEGNet 内层早停要求矛盾，现改为检验准备阶段拒绝和接口边界。其他小型 EEGNet 数值回归仍由原有专门测试承担。
