# 有预算的离线预处理探索

数据接入完成后，搜索器从基础方法和有来源的方法配方出发，探索算子组合，在冻结的开发协议下选择共享预处理规则。实际评分所用的表示用于训练交付。已有运行的产物保持只读，算法与说明的历史由 Git 保存。

## 算子、方法与科学先验

算子是可执行操作，方法是有顺序、有参数的完整算子组合。每个算子有输入输出阶段、允许的参数域、默认值来源、拟合信息权限、上下文要求和执行实现。模型通过 JSON Schema 提交配方编辑，验证器检查合同后才编译；模型不能写任意执行代码。

当前起点包括 8–30 Hz 平均参考、宽带平均参考、采集参考、文献适配的 EA、坏通道诊断及插值、严格 ASR 加坏通道修复、条件 ASR 加坏通道修复，共七种。清理方法只在依赖、通道及电极位置满足条件时进入空间。它们是注明差异的组合方法，不宣称完整复现 PREP 或 clean_rawdata。可选算子还包括去趋势和显式 50/60 Hz 陷波；是否需要陷波应参考实测频谱。

允许五类编辑：参数域内调参、插入算子、移除可选算子、相邻换序、改变无标签适配规则。固定任务切窗与输出网格不能编辑。内容哈希排除节点显示名称和未使用的条件阈值，拒绝重复与实际没有改变的方案。`registry.json` 保存起点、父方案、编辑和完整结果配方。

科学依据目录覆盖 25 类操作的 300 组两两关系，保留来源、条件性结论、冲突和证据缺口。这是研究范围，不表示 25 类操作都已接入。运行合同只采用能准确表达且适用于当前实现的约束：

- 硬约束包括数据类型、依赖、数学条件及当前实现的限制，违反即拒绝。
- 软先验表示经验倾向；模型可挑战，但必须登记具体理由与可检验预测。
- 参数域中的工程选择明确标注，不能被解释成文献给出的最优阈值。

坏通道诊断算子编译为检测和显式标记；标记引用检测时的同一信号，随后才可执行 ASR 或插值。超过最大坏道比例则报告失败，不能偷偷放宽限制。当前 ASRpy 0.0.8 适配器要求有效的满秩校准空间，因此限定在平均参考和插值之前；这不是跨实现通用的唯一顺序。自动 ICA 删成分目前没有纳入 EEGMMIDB 搜索空间：不能伪造 EOG 通道，也不能忽略分类器训练域和本数据采样率的差异。

ASR 检查实际输入高通支持与校准窗口的关系，前置带通也可满足条件，不强制重复高通。严格策略在校准不足时失败；条件策略仅对校准时长不足保留该步骤输入、继续其余操作，数值、秩及依赖错误仍失败。逐记录保存实际校准秒数、ASR 是否应用及原因；跳过的记录仍参与完整评价。

## 数据范围与信息权限

默认使用路径调研所得全部被试及全部源 Run。左右手运动想象评价依据明确的任务映射使用 R04/R08/R12，其余 Run 保留在源清单中。不得将含不同任务的全部 Run 混成同一个二分类问题。

默认冻结最多五折被试分组交叉验证，每位被试恰好一次折外预测，同一人的所有记录留在同一折。五折是工程选择。共同的无效窗口在探索前确定，候选必须覆盖全部共同合格试次，不能通过丢弃难例提高评分。来源采样率按实际文件头读取，先重采样到共同网格，不能把 128 Hz 文件直接标成 160 Hz。

EA 和条件 EA 可读取目标被试的完整无标签批次，属于离线转导协议。分类器、特征选择及内层调参只使用外折训练被试；目标标签仅用于开发评分。EA 输出是无量纲线性表示，不能当作原电极电压。条件门控阈值是待检验的工程参数。

同一开发面板会被反复用于选择，因此这些分数不能充当独立测试成绩。不能将当前开发被试重新命名为独立确认集。跨被试、被试内、不同试次筛选和不同目标信号权限的论文结果必须分开比较。

## 三层评价

| 层次 | 计算和用途 | 解释边界 |
| --- | --- | --- |
| 训练效用 | 固定 EEGNet 主模型，种子 17、42、2026 各自先对被试 BA 等权平均，再对三个种子等权平均；作为选择主指标 | 任一种子不完整则主指标为空，不能平均剩余种子。反映共同模型与开发协议下的效用 |
| 模型对照 | 仅 CSP-LDA 为基准对照；另报 accuracy、F1、kappa、AUC、Brier、log loss、被试离散程度与低四分位 | 不用于临时替换选择主指标。硬预测没有概率指标；不伪造 AUC |
| 信号质量 | 物理电压阶段的 25 项质量和保留指标；逐记录、逐被试及总体汇总，保留阶段与单位 | 缺失和不适用保留原因，不填零，不按任意权重合成质量总分 |
| 半合成重建 | 向实际 EEG cleanproxy 注入已知污染，分别执行 P(x) 与 P(x+a)，比较残余污染、重建和对原信号的保留；含恒等、零输出、收缩对照 | x 不是已知纯净神经真值；不能只看降噪而奖励零输出或过度衰减。物理阶段实验不认证 EA 保真 |

当前展示协议为 `utility_version=2` / `assessment-v2`，`primary_suite=['eegnet']`，`learner_scores` 仅含 `eegnet,csp_lda`。历史 v1 仍按保存的六模型与三主模型均值标签显示，不改写历史成绩。种子摘要、逐种子指标及产物结构见[评价阅读说明](preprocessing-evaluation.md)。主模型完整分母为 1，预测分母为 3×N；仅全部三个种子完成才记录 3×N 可用预测。质量 25 项和重建 14 项保持独立。

质量评价读取全部记录。任务前基线必须来自与任务片段同样处理的连续快照，核对来源、事件和数值后才计算 ERD；越界、重叠任务、不能确认前一任务结束等情况逐试次标为不适用，不拿原始基线替代处理后基线。

重建探索默认每名被试固定第一条任务记录，并使用其中全部合格试次；十个污染条件按固定哈希顺序均衡分配，每名被试参加一个条件。同一个冻结分配用于所有候选，逐条件分母明确。`full_factorial` 模式对每名被试执行全部条件，可用于最终方案追加确认。该探针设计不缩减分类评价的全部记录和全部被试。

## 探索决策与预算

LLM 接收冻结资料、方法起点、算子域、先验、实测摘要、覆盖统计及剩余预算。自适应提案必须引用真实数值路径，登记机制与竞争解释，分别预言信号和效用变化，说明什么结果会削弱解释。程序比较实测结果与预言，并把反例反馈给下一轮。故障不是零分，信号预测失败而效用改善也不能确认原来的机制解释。

先覆盖不同方法家族，再从实测父方案探索局部编辑，避免持续只微调一个频带。提前停止须解释未探索方向；当前最低编辑覆盖数是工程防止过早停止的规则，不是统计充分性证明。定向阅读使用冻结来源；科学先验概述与原始文献明确区分。

默认预算为 48 个候选、128 次提案、32 次阅读、86400 秒，最多 4 次暂时故障重试。内存与磁盘留空时按启动资源确定。预算包含预处理、评价、模型调用、失败和停机；恢复不重置期限。

随机、枚举、一次性提案对照共享预先冻结的有限邻域，最多 256 个方案：保留全部起点，加入参数域分位值、合法相邻换序、插入、删除及适配变化，按编辑类型和方法家族均衡排列、语义去重。生成及排除原因保存在 `control-design.json`。枚举指这个有限邻域，不是连续空间的穷尽。自适应搜索允许多代编辑，与有限对照的空间不同；不能把差异全部归因于反馈作用。

最终由程序选择完整主指标最高者；精确平分时依次优先固定参考、较少算子、候选编号。质量与重建证据独立展示，不事后修改权重。性能目标必须在可比人群、任务、时窗、划分、指标与信息权限下评价，不能继承论文的高分或以目标分数填补失败。

记录级计算使用受监督的独立进程，数值线程限制为一，父进程写任务状态并检查资源。取消或父进程退出时回收子进程；已校验的完整记录可在同一冻结环境中恢复。源数据始终只读。

EEGNet 使用 CPU（PyTorch 2.8 CPU、单数值线程），默认最多 100 epochs、patience=15，约 20% 外折训练被试用于内层验证；外折开发被试不参与早停。默认 batch size=64、learning rate=0.001。服务冻结 `utility_execution.eegnet_training` 与 `utility_protocol.eegnet`，模型进程并发上限为 2。评价执行和并发以运行冻结的协议为准。展示层读取完整种子指标及来源，不把 EEGNet 顶层空 folds 当作失败；模型位于各 seed 的 folds 中。资源不足不能删种子、删折或删被试来产生主分数；超时、内存限制和取消不转成低分。已移除为旧 FBCSP 子带设置的最低 8 Hz 带宽限制；带通仍须在允许域内，当前低截止范围 0.5–15 Hz、高截止范围 20–60 Hz，保持低截止小于高截止并低于奈奎斯特频率。本次不运行真实探索。

## 产物与使用

| 文件 | 内容 |
| --- | --- |
| `protocol.json`、`limits.json` | 数据、数值实现、评价器、信息权限和资源上限 |
| `space.json`、`scientific-knowledge.json`、`evaluation-evidence.json` | 算子域、方法起点、执行先验、文献关系及指标和基准研究目录 |
| `panel.json`、`probe-panel.json` | 全部原始试次与被试折、固定重建探针分配 |
| `registry.json`、`coverage.json` | 配方谱系及方法、算子、编辑类型的实际覆盖 |
| `control-design.json` | 非自适应对照的冻结有限邻域、提案及排除原因 |
| `search.json`、`decisions/` | 状态、动作、真实模型请求与结构化答复 |
| `candidates/<id>/policy.json`、`method.json`、`plan.json`、`result.json` | 完整配方、编译方案和逐记录执行 |
| `candidates/<id>/receipt.json` | CSP 锚点、实际评分表示与统一评价摘要 |
| `candidates/<id>/assessment/aN/` | 每次完整评价尝试的效用、质量、重建、预测、拟合模型及校验索引 |
| `candidates/<id>/core-receipts/aN.json`、`operator-usage/uN.json` | 评价输入的原核心回执，以及独立的算子应用计数和逐记录证据 |
| `candidates/<id>/adaptation/` | 无标签拟合参数和实际评分数组 |
| `selection.json`、`report.html`、`files.json` | 最终选择、可读报告和全部文件下载索引 |

主入口 `/workflows`；独立探索 `/searches?workflow=<运行编号>`；运行详情 `/searches?id=<搜索编号>`。运行页按候选、探索空间、评价与文件呈现，避免把所有明细展开成长页面。

API：`POST /api/searches` 创建，`GET /api/searches/<id>` 查询，`POST /api/searches/<id>/cancel` 取消，`POST /api/searches/<id>/retry` 在冻结环境和剩余预算内恢复。

生成数据、日志、模型和预测保存在被忽略的 `backend/workspace/`；源码、Schema、依赖锁、测试及当前说明进入版本控制。
