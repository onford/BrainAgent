## 2. 项目概况

BrainAgent 面向 EEG 数据研究与训练交付，当前主要落地数据集为 EEGMMIDB，主要任务为左右手运动想象二分类。目标是把资料与本地数据核对、标准化接入、诊断驱动的预处理探索、数值评价、报告和训练数据交付串成可追溯流程。

六模块：数据调研 → 数据接入 → 数据预处理／策略搜索 → 结果选择 → 报告 → 训练交付。主要页面入口 `/workflows`，关联搜索页 `/searches`；另保留聊天、工具集成等能力。

技术栈：Vue 3、TypeScript、Vite、Pinia；FastAPI、Pydantic、SQLAlchemy；本地 SQLite；EEG 数值执行使用独立 Python Worker，依赖 MNE、NumPy、SciPy、scikit-learn、ASRpy、PyTorch CPU。LLM 使用 OpenAI-compatible Chat Completions 接口。

职责边界：LLM 核对文献、组织解释、提出竞争假设与可检验预测、选择下一项实验；程序负责测量、参数拟合、处理、训练、预测、评分、合同校验和最终选优。报告的数值、处理顺序和单位来自结构化记录，不能让 LLM 改写。

## 3. 当前实现的预处理探索机制

- 算子是探索单元，完整有序算子组合才是方法；以基础和文献方法为起点，不再是早期固定 24 个组合的简单目录选择。
- 七个起点：8–30 Hz 平均参考、宽带平均参考、采集参考、EA、坏通道修复、严格 ASR＋坏通道修复、条件 ASR＋坏通道修复。
- 支持参数调整、插入算子、移除可选算子、合法相邻换序、改变无标签适配规则；固定任务切窗与输出网格不能编辑。
- 提案通过 JSON Schema、参数域、依赖、数据权限和科学约束校验，不执行 LLM 任意生成的代码；按内容去重。
- 硬约束不可违反；软先验可以挑战，但必须登记依据、竞争解释及可检验预测。科学知识目录覆盖 25 类操作、300 组两两关系，不等于这些操作都已实现。
- 先覆盖方法家族，再根据反馈编辑已有方法。保存配方谱系、决策、预测核对、实际算子应用、模型及文件哈希。
- 默认预算为 48 候选、128 次提案、32 次阅读、86400 秒，暂时故障最多重试 4 次。这是配置默认值，不是本次交接授权执行的工作量。
- 自动清理目前包含注明实现差异的坏道处理与 ASR，不能宣称完整复现 PREP／clean_rawdata。自动 ICA 删成分尚未纳入当前 EEGMMIDB 空间。

## 4. 新评价协议：必须准确继承

`utility_version=2` / `assessment-v2`；核心评价回执已升为 v3，面板版本独立，不能把所有版本号混为一谈。

**唯一选择主指标：EEGNet 在种子 17、42、2026 下各自的被试宏平均 BA，再对三个种子等权平均。**

- `primary_suite=['eegnet']`；`learner_scores` 仅含 `eegnet`、`csp_lda`。
- CSP＋收缩 LDA 仅为经典对照，不参与选择；任一种子未完整完成，不能用 CSP 或剩余种子填补主分数。
- 所有候选使用相同被试、试次、外折、模型配置、训练预算及种子，从头训练，不继承其他候选权重。
- 默认最多五折，按被试分组，同一人的全部记录在同一折。早停验证只从外折训练被试划出约 20%，按固定且与标签无关的排序划分；至少保留一名拟合被试。外折至少两名训练被试，否则准备阶段拒绝评价。
- CPU、单数值线程；最多 100 epochs，patience=15，batch size=64，learning rate=0.001；内层 trial log loss 最低的 checkpoint 胜出，首次最低优先，不额外 refit；模型进程并发上限 2。
- 五折意味着每候选 15 次 EEGNet 训练，另有 CSP-LDA 五折评价。资源不足只能降低并发或停止，不能暗删种子、折或被试。
- 选择完整主分数最高者；精确平分依次优先参考方案、较少算子、候选编号。
- 25 项信号质量、14 项半合成重建指标及其他分类指标用于解释与诊断，不事后加权改变选择规则。
- 种子 SD 表示训练随机性；被试 SD／Q25 表示个体差异，不能混用。缺失 Q25 不自行补算。
- 主模型分母为 1；完整预测为 `3×N`；顶层被试 `n_trials` 仍为 N。EEGNet 顶层 `folds=[]` 是合法结构，各种子自己的 folds 保存 `model.pt`，合并预测每行包含 seed；CSP 保存原 folds 和 joblib 模型。
- 旧 utility-v1／assessment-v1 的三主模型平均分必须保留历史语义，不改名为 EEGNet、不按新公式重算。

## 7. 工作原则

1. **以最新用户要求为准。** 当前暂停真实探索。继续一般修复与已授权工作不反复询问；恢复长时间真实搜索须有新的明确开始指令。
2. **科学诚实。** 不虚构来源、EOG 通道、分数或成功状态；研究覆盖不冒充实现覆盖；小样本／合成测试不冒充全集实验；开发高分不冒充独立测试或 SOTA。
3. **冻结且公平。** 候选不能通过删困难被试、删试次、挑种子或修改评价器提高分数；合法的共同排除规则须在探索前确定并记录。
4. **严格区分信息权限。** EA 读取目标整批无标签数据属于离线转导，不是零目标信息或实时协议；目标计分标签不能进入拟合、早停或个人选择。
5. **单位、阶段和语义一致。** EA 后无量纲表示不能沿用电极电压阈值；真实采样率必须读取并正确重采样；同形数组不保证任务语义相同。
6. **失败与缺失保留原因。** 不适用不是零；条件 ASR 仅针对指定校准不足情形跳过，数值、秩和依赖问题不能吞掉；质量变好不自动证明训练受益。
7. **保护历史与原始数据。** 原数据只读；旧运行按原协议阅读，算法变化后应创建新冻结运行，不能原地“续跑”并覆盖历史成绩。
8. **保持版本清晰。** 每版可用修改按项目约定提交；历史实现用 Git 保存，不堆 `_old`、`_backup`、旁路 v2 目录。此前项目提交作者使用 ljy，接手提交前核对既有身份配置。不要覆盖或删除已有未提交文件。
9. **代码与运行产物分开管理。** 密钥、数据库、EEG、运行输出、日志、依赖不入源码 Git；需修订的报告使用 `.local/artifact-history/<运行ID>.git` 的独立本地历史，保持唯一正式路径并更新哈希及交付包。
10. **验证与改动相称。** 完成必要回归后推进交付，不因没有新问题而无限扩大测试。报告说明测试范围和局限。
