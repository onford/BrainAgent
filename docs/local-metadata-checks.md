# 本地元数据与独立事件文件核查

本地观察现在保存 BIDS 根目录候选、数据集/采集/电极/坐标 JSON 和参与者/行为/刺激 TSV 的结构化声明、缺项、文件大小及 SHA256。声明不等同于实测事实；模板电极位置不能变成个体实测坐标。尚未实现 BIDS 元数据继承及逐记录适用关系，也没有从 EDF 自由文本、PDF 或图片猜测人口学与设备参数。

读取上限为单文件 4 MiB、总计 64 MiB、单表 10000 行；超限明确保存未检查或部分检查。重复 JSON 键、非有限数字、重复表头、错列以及路径越界不会静默接受。完整表格留在本地产物，模型上下文只带摘要。发现 BIDS 目录不代表通过官方校验。

EEGMMIDB 的 `.edf.event` 使用固定 WFDB 4.3.1 作者字节解码器独立读取，包括 sample=0 的真实注释。该版本高层 `rdann` 会将 sample=0/type=22 视为可能的格式定义，因此比较使用其原始字节解码层，并显式识别时间分辨率与 T0/T1/T2 duration 注释。未知注释保留为无法完整核查，时间和持续时间比较容差为半个采样点。读者版本及解码源码哈希进入回执。比较不修改信号、不推断任务标签、不自动排除记录。

全部 1526 条本地 EDF（109 人、每人 14 Run）实测得到 1260 组一致、266 组注释数量不同：218 组来自全部 R01/R02 静息记录，另外 48 组来自 S088/S089/S092/S100 的全部任务 Run。EDF 共 39569 个注释，WFDB 共 38641 个。官方 SHA256SUMS 与本地字节一致，3052 个 EDF/事件文件全部符合该清单，另直接下载三个事件文件交叉核对。差异属于已发布文件之间的可复核差异；这不能判定哪一份注释具有正确的实验语义。

全量比较读取 3614542346 字节，132.828 秒，源数据与冻结源码不变。最后 29 项相关测试通过，2 条警告，55.69 秒。另 ad18d2b 固定版本全量后端回归 1306 项通过、109 警告、835.95 秒；它覆盖前批步骤复核，不能代替本批新增功能验证。

证据：[逐记录审计](sources/remaining-modifications-20260912/metadata-live-1-audit.json)、[官方文件对应验证](sources/remaining-modifications-20260912/metadata-official-proof.json)。作者接口见 [WFDB 文档](https://wfdb.readthedocs.io/en/latest/io.html)，发布信息见 [PhysioNet 数据页](https://physionet.org/content/eegmmidb/1.0.0/)及其 [校验清单](https://physionet.org/files/eegmmidb/1.0.0/SHA256SUMS.txt)。
