# 固定传感器配对差值与基线敏感性

2026-09-13，第二十二批，I20。

`sensor_lateralization` 读取已验签的任务/提示前 Welch ERDS 测量，不读取类别标签。固定使用 C3 与 C4，μ 为 8–12 Hz、β 为 13–30 Hz；计算每个原始试次的 `ERDS(C3) − ERDS(C4)`，单位为百分点。该指标没有优劣方向，不表示对侧/同侧，不定位神经源，也不用于选择个人处理方案。

必须有两个通道、原始试次标识及顺序、同一处理的真实 −2.5 至 −0.5 秒半开基线、逐窗支持审计、有限 ERDS 和严格正的基线功率。父质量分析的频带/已有陷波限制继续生效。先验条件不满足时，完整试次仍留在分母中，总体结果为空，不用原始基线替代缺失的处理后基线。

新质量摘要保存两通道逐试次基线功率、ERDS 与差值，绑定物理测量框架；诊断重新核对差值和均值的算术一致性。先对试次等权，再对同一人的记录等权，最后对参与者等权。记录/参与者未访问、缺测或重复身份均不能产生完整总体标量。参与者分组只服务统计，未用于拟合或选择预处理配方。

各记录保留基线功率的最小值/中位数/最大值、逐试次原值和留一试次均值范围；总体保留留一参与者均值范围。这些是描述性的敏感性分析，不是假定试次相互独立的置信区间，也没有覆盖率保证。生理来源、基线平稳性、真实神经保护及正式统计不确定性仍需独立验证。

74 项后端专项通过（24.06 秒），包括原始 BIDS→质量分析→配对差值集成、数据框架与试次顺序、零基线、缺失成员、分组等权和注册诊断实际数值分支。前端全量 160 项通过；构建发现模板索引类型比较问题，改为显式字符串转换后相关组件 6 项复测及构建通过。

真实只读复核见 [审计](sources/remaining-modifications-20260912/lateralization-live-1-audit.json)：4 名参与者、12 记录、180 试次。准备阶段验签读取约 220.1 MB 的既有质量明细，生成新摘要；两次正式诊断各读取 3,844,298 字节，耗时 0.063/0.094 秒。总计 3.422 秒，原文件和代码不变，没有重新预处理或分类。
