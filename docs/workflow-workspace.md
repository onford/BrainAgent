# 运行页的阅读工作区

页面分为运行操作栏、六阶段进度条和内容工作区，桌面端按视口高度布局。进度和当前操作保持在阅读区上方；正文、文件列表和日志各自在内容窗口中滚动，避免把所有模块纵向堆叠。

- **流程与证据**：默认阅读入口。将决策概览、信号图表、评价指标、预处理方案与 Agent 决策记录连到关联搜索的具体页面；报告和文件仍可直接切换。未绑定唯一搜索的历史流程列出使用相同数据流程的搜索，由用户明确选择查看，且不改变原交付的归属；没有可读记录时明确显示证据缺口，不补造图表或选择理由。离线导出将未嵌入的搜索入口标为在线可查看。
- **报告阅读**：目录按“处理结果、数据认识、方法依据”分组，每篇附阅读用途，可按标题、主题或用途搜索。仅列出已生成的报告，补充材料归入“其他报告”。首次打开时优先展示最终处理报告；运行中新增报告不会打断当前阅读。
- **篇内导航**：切换到“本篇章节”，按实际 HTML 的二、三级标题展示层级，并随正文滚动提示当前位置。逐记录明细与表格内的重复标题不进入目录；跳转到折叠章节时自动展开正文。切换报告时记住本次会话的滚动位置，切换工作区视图时保留已打开的报告。专注阅读收起顶部区域，按 Escape 或“退出专注”恢复。保留新窗口打开和原始 HTML 下载。
- **记录文件**：按模块筛选，支持文件名和中文说明搜索；同类文件仍默认折叠，全部产物可逐个下载。阶段详情中的“查看本阶段文件”直接定位对应模块。
- **执行日志**：最近的记录在前，可搜索操作和执行主体；进度条下方只显示最新操作的简短预览，点击可查看完整日志。
- **训练数据**：集中显示训练数组规模、下载链接与使用说明，交付前显示等待状态。
- **运行操作**：历史运行通过顶部选择框切换；新建流程与阶段详情使用原生 dialog，支持键盘关闭与焦点返回。长错误文本仅在详情窗口展开，不撑高进度栏。

小屏幕下通过“目录与章节”展开导航，选择报告或章节后自动收起；文件模块导航改为横向按钮。报告内部宽表保留局部横向滚动。查看层只调整 iframe 中的显示样式，不改写已冻结的报告文件或其哈希；报告仍在禁用脚本的 sandbox 中显示。离线导出使用相同的阅读组件，验证时按报告路径核对正文，不依赖目录位置。

组件位置：`frontend/src/views/WorkflowsView.vue`，`frontend/src/components/workflows/ReportReader.vue`，`frontend/src/components/workflows/ArtifactExplorer.vue`。

搜索页默认展示“决策概览”，从保存的选择、候选主评分图和近期决策核验进入详细证据。主评分按运行及候选的评价版本解释；缺失 EEGNet 主分数不使用 CSP 锚点填补，不在前端重新选优。提案理由与最终选择分别展示，未正常完成的运行保留状态提示。`view=assessment&axis=quality` 可直达信号图表，`axis=parameters` 可直达实际执行与参数。
