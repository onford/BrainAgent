# EEG 训练数据工作流

在运行页输入 EEGMMIDB 源目录并开始。系统依次执行数据调研、数据接入、预处理策略搜索、结果选择、报告和训练交付。默认调研全部本地被试和 Run，训练任务为左右手运动想象；任务标签由来源和文件事件核对。

数据接入完成后，预算搜索自动启动。运行页可进入关联搜索查看折外评价、个体适配、实验假设和预测核对。默认采用全部已接入任务被试的分组交叉验证；自适应搜索调用 LLM，数值处理与评分由独立工作进程完成。

报告页按数据集信息、数据信息、统计、三类文献和最终处理结果组织。记录文件保留稳定格式、概要及下载链接；同形文件分组展开。训练包中的 X、y、被试与事件清单逐行对应，并附带实际处理策略和表示变换。单位由 channels.json 声明，适配后的无量纲坐标不能当作电极电压。

开发面板交叉验证的分数用于选策略，不是独立测试成绩。交付保留搜索折清单，不重新分配一个声称独立的测试集。数据可以用于后续训练；泛化确认需要未参与当前策略开发的数据。

参数、预算、信息权限、产物格式及 API 见[预处理策略搜索](offline-preprocessing-search.md)。数值与 LLM 角色见[工作流职责](llm-workflow-redesign.md)。
