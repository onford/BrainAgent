2026-09-11。本次已把神经先验接入实际搜索控制器、数值诊断、候选校验、质量报告和界面，完成第一条真实数据决策闭环。此前路线中的全部科学研究与跨任务验证尚未完成，不能把这次工程验收解释为“已证明最佳预处理”或“已证明神经信息无损”。

## 真实运行与效果审阅

没有使用假模型回复代替实测。使用项目配置的 **deepseek-v4-flash** 和生产 `SearchService`、FastAPI 搜索路由、实际预处理/评价子进程。HTTP 测试通过本地进程内 ASGI 执行，仅替换测试身份依赖；因此它验证了生产路由行为，未验证登录或现有服务器的部署切换。

测试在评分前固定 EEGMMIDB **S001–S004、R04/R08/R12，共 12 条记录、180 个试次**。S001–S003 用于训练，S004 是开发留出被试。使用 100 个文件的独立副本，并在最终检查再次核验原文件与副本全部哈希一致。三种子 17/42/2026、原有 EEGNet 训练上限 100 epoch、早停与评价协议保持冻结。

最终运行 `3d6d5daa63f24565a3bf46f5a416584a` 用时约 **335 秒**，发生 **3 次真实模型调用、1 次模型主动诊断、1 次无效提案拒绝、2 个完整数值候选**，按预先设定的候选预算正常停止。诊断下载路由返回 HTTP 200，内容与账本一致；结束后再次核验当前代码、环境和运行冻结哈希一致。

| 候选 | 三种子平均开发 BA | 解释 |
| --- | --- | --- |
| 8–30 Hz＋平均参考 | 0.502635 | 固定参考 |
| 同一物理流程＋逐被试无标签 EA | 0.537549 | 本次开发面板按冻结规则选中 |

差值约 **3.49 个百分点**，只说明这一固定小面板上的开发结果。一个开发被试、两个候选、反复开发反馈不足以证明泛化改进、神经保留或生理机制。最终提案对 floor_fraction 不变的信号预测得到满足，但这也是较弱的数值退化检查，不能代替强神经保护证据。

此外，使用最终代码对真实两候选运行了配对诊断：4/4 被试可配对，物理任务协方差迹差为 0，符合 EA 位于物理预处理之后的设计。此项是工程人员的运行后核验，**不是模型主动请求的第二次诊断**。

### 实测发现的问题及修复

1. 首次缩小输入清单却沿用完整根目录，被完整性检查拒绝。改为逐文件核验的独立测试副本，未放宽清单检查。
2. 模型多次猜错 `quality.metrics.*` 路径；校验还漏认了合法的 `assessment.core_csp_macro_ba`。修正分类、提供真实数值路径清单，并把可操作纠错提示写入拒绝信息。
3. 中间一次运行预测 EA 会降低 `mean_anisotropy`，实际它是 EA 前的门控量。修正阶段标注，并加入执行前的不变量校验。保留中间运行的错误预测，不以分数上升掩盖解释错误。
4. 聚合层 `no_available_members` 无法解释真正缺失原因。诊断现在核验并读取逐记录明细，最终显示是采集滤波历史不完整，而非 50/60 Hz 污染不存在。
5. 增加结构化 `prior_claims`，防止把未知条件在引用中偷换为成立。反事实缺测测试同时移除矛盾的历史文本，避免测试本身保留旧数值。
6. 界面实查发现 EOG / 输入域条件标题可能读反。界面改成“至少一条记录缺少真实 EOG”“原始带宽不足以覆盖 1–100 Hz”，并补充中文缺失原因与原始测量链接。

最终运行仍发生一次结构化提案字段放错层级；控制器拒绝后模型修正，未消耗一个数值候选。系统的可信性依赖可核验约束和纠错，不依赖模型永不出错。

- 前端全量测试：**126 passed**；TypeScript 检查和生产构建通过。浏览器实际审阅证据卡展开、来源定位、未知提示、时频分页、色标与边缘灰区。预览采用真实回执，未冒充已部署的业务页面。
- 两项额外真实模型 API 反事实测试：缺测上下文、包含“制造典型 ERD / 缺失填零 / 自动 ICA”指令的不可信资料。最终回复通过引用状态、实际数值路径、测量阶段、配方编译检查；未执行反事实提案。缺测案例选择不用缺失先验，基于现存效用证据提出另一对照；注入案例没有采纳上述错误操作。
- 反事实回复仍可能使用“方向成立”“单变量可比”等偏强或不够精确的自由文字；结构化合法不等于全文科学解释正确。更大规模专家标注和自动忠实性评测仍未完成。

复现脚本位于 `backend/scripts/neural_prior_smoke.py` 与 `backend/scripts/neural_prior_review.py`；均调用项目配置的真实 API，不在源码中保存密钥。原始请求、回复、数值回执、失败过程和最终校验存于 `.local/neural-prior-*`，机器可读清单记录其路径和哈希。
