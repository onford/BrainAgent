# 步骤检查点、复核与共享替代计划
> 2026-09-13 范围更新：保留首次推荐，移除后续模型自主调整。当前规则见[首次推荐与固定执行](fixed-initial-recommendation.md)。本文中的历史自主调整验收不再作为当前目标。

2026-09-13，第二十三批，I22。

v2 图在每步完成后写入不可覆盖的 `checkpoint.json`：输入/输出/根数据哈希、编译步骤与依赖图哈希、原始事件/试次、参考和单位、数据/模型 Codec 描述符、文件清单、步骤后观测与条件结果。Codec 继续保存原始精度数组和模型；检查点验签覆盖实际文件。进程中断留下的不完整文件不会在原位置修补。未声明新条件时，Step 序列化省略空字段，保持历史计划字段表示。

可事前声明的工程条件为有限样本比例、最大绝对值、RMS、相对输入的事件/通道保留比例；每条必须有阈值、比较、理由和失败行为（仅记录或暂停）。观测缺失不能当作条件成立；要求暂停的条件失败后，先保存检查点与执行日志，再进入已有 `waiting_decision` 状态。没有自动删除坏片段、关闭科学条件或重新拟合个人配方。

接口：

- `GET /api/preprocessing/jobs/{job_id}/step-reviews`：核验用户所属任务、已停止的尝试及持久化产物哈希，返回条件与观测。历史没有检查点的步骤不补造。
- `POST /api/preprocessing/jobs/{job_id}/shadow-plans`：请求绑定记录 key、检查点步骤/哈希、同 ID 的替代 Step 和理由。只允许替换该步骤，保留其原条件；不能提交逐记录的不同替代策略。分区内部重放检查点不授权完整记录替代。
- `data_preprocessing` agent 仅保留 `step_reviews` 读取；`shadow_plan` 已从模型动作中移除。共享替代计划只接受用户显式 REST 操作。页面提供只读复核、缺测和失败产物下载；替代计划独立显示为待运行，不宣称已经执行。

替代方法标明工程派生，保留父方法/计划/任务、原步骤、新步骤、理由和检查点哈希。改变的参数明确标为工程来源，不能继续称为论文原值。使用当前知识、参数、依赖、单位/通道/时间与资源条件重新编译，覆盖原输入的全部选中记录且使用一个共享方法。旧方法/任务/失败文件不修改。原生产任务的未验证替代只能形成 exploratory 计划，不能直接作为生产验证通过的方案。

恢复策略是**从不可变原始输入重新执行共享图**；本批没有从中间检查点恢复任意拟合对象的缓存加速。完整重新执行能够让模型、诊断与数据绑定重新接受检查，代价是重复前缀计算。失效来源、不同引擎/环境、篡改检查点、错误频带、放宽停止条件或不完整原记录覆盖均阻塞替代。失败与等待状态的持久化回执保留检查点引用，供后续验签和下载。
