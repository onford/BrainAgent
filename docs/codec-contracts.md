# 底层产物描述合同

新写入的信号、模型和诊断容器使用 `artifact-codec-2` 描述，每个容器声明版本。能力 API 同时提供这份 JSON Schema；生产者和解码器使用同一封闭字段定义。未知 codec、未知版本、额外字段、缺失字段、未经描述的数组或非有限原始 JSON 数字不能静默通过。非有限数值只允许以明确 token 或验签数组保存。

未带版本的历史描述仅按已知旧字段读取，包括早期可缺少精确 info/times 的信号和 HDF5 AutoReject。不会把历史任务恢复为当前执行或覆盖旧产物；新输出始终使用新合同。

对象数组元素数须覆盖完整形状；字典键不能重复或因缺少键值对而丢失。CSR 数据、列索引和行指针须符合矩阵维度。信号数组轴须符合 FIF 文件形状，电极位置数与通道数对应，时间轴与信号采样网格对应，Epoch 事件/选择轴与试次数对应。文件内容仍逐一验证 SHA256，数值与状态往返仍比较完整指纹。

MNE 的命名整数常量在新描述中显式转为 JSON 整数，数值不变。首轮新增检查误拒绝这些常量，21 项测试失败；修正序列化后 41 项回归通过，最后包含分区、步骤复核、并行执行、原生进程和结果完整性的批次 77 项通过、2 警告、65.64 秒。JSON Schema 本身和代表性描述已由固定 jsonschema 4.25.1 验证。

真实历史兼容检查覆盖 12 条完整信号描述及一个完整 RELAX 原生步骤产物容器（共 13 个顶层描述）。旧文件只读解码，新版本另存独立验证目录；全部完整数值/状态指纹往返一致，12 条信号与独立保存的 signal_V.npy 最大差 0 V。原文件和冻结代码不变，10.296 秒。见 [审计及原文件哈希](sources/remaining-modifications-20260912/codec-legacy-live-1-audit.json) 与 [可共享 JSON Schema](sources/remaining-modifications-20260912/artifact-codec-2.schema.json)。

这批完成的是底层容器和结构一致性检查。异构算法诊断中各字段的科学定义、单位、分母、适用条件与所有消费者的严格语义合同仍未全部统一，I44 保持部分完成；文件可解码不能代替指标语义验证。当前能力矩阵如与新引擎哈希不一致，继续显示历史/过期，不提升为已复验。
