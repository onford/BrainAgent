# 评估页面信息分层（2026-09-12）

默认显示当前结果、数据范围、完成情况及影响判断的限制。补充规则和完整证据按需展开；不改变评估数据、模型解读内容或图形规格。

| 内容 | 展示位置 |
| --- | --- |
| 信号诊断范围与开发集范围 | 实例页顶部明确区分；样本划分、种子预测数和泛化限制在“样本划分与评价口径”中 |
| 当前指标 | 图表、状态和缺失原因保留；被试覆盖与模型解读紧接当前汇总图 |

| 表格范围 | 明确说明表格汇总所选阶段的被试结果，单条记录选择仅影响图表 |
| 训练评价 | 主模型和预测覆盖保持可见；计分口径、种子波动汇总、逐种子统计与文件可展开 |
| 重建评价 | 污染去除与原信号保留、不同条件可能使用不同被试的限制保持可见；完整实验设计可展开 |
| 参考资料 | 阅读指南按主题列出；展开主题可查看原有解释、适用条件、替代解释和引用 |
| 导出与对比 | 图表仍可勾选对比；SVG / JSON 收入“导出”菜单，文件内容保持一致 |

“评价完成情况”明确区分完成评价与质量合格。原始测量记录在模型解读失败或尚未返回时仍可查看。实例页通过 `hideAxisNavigation` 复用外层导航；正式应用保留组件自身的评价维度导航。

实测在 1440 × 1100 的浏览器中，信号质量页默认可见字符从 2517 减至 1191（约 53%），首图顶部从 1240 px 移至 867 px。该计数描述页面显示密度，不代表经过用户研究测得的认知负荷。
