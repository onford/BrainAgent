# 共同视图的波形和时间变化

`common_view_change` 是可请求的注册诊断，读取同一记录已验签的共同视图电压数组。它要求完整的共同参考/频带合同、相同原始样本网格、通道及试次身份；只允许 `processed_task` 阶段。缺少历史合同、未访问的记录或不一致的样本/试次数量不能被当成完整测量。

测量包括：

- 未移动时间、未缩放振幅的变化NRMSE和相对增益。
- 零时移波形相关。
- 固定±100 ms范围内的相关最大值位置。各偏移使用明确的重叠样本，不做循环连接；多个同等最大值、搜索边界最大值或常量信号返回不可辨识。寻找相关峰不改变NRMSE的输入。
- 按平方电压加权的时间重心变化。它也会受幅度和形态影响，不能单独解释为时间延迟。

先对每条记录的全部试次/通道对等权，再对全部记录等权；缺失不从分母中删除。每条记录保存完整统计分母和最多四个不可辨识例子，例子是否截断显式记录。已验签的完整输入数组及固定参数可重算每个配对测量。

此诊断没有波形对齐、幅度拟合或个体预处理。共同分析滤波仍有边缘效应，全部提供的窗口参与测量。相关峰偏移不是生理潜伏期，相关高也不代表幅度保留、神经来源或纯伪迹去除。

验证：已知40 ms延迟、周期等高峰、边界峰、零输出、缩放、非有限值、缺失通道、记录漏计和物理数组篡改均有回归。最终95项后端专项、158项前端测试与构建通过。

真实复核使用既有12记录/180试次的共同视图，在新的只读分析目录中把原明细里已验签的合同加入新摘要；原质量回执和数组不改写。读取62198806字节，用时4.172秒，原文件及复核代码哈希不变。未对齐变化NRMSE为0.155631，增益0.941528，零时移相关0.987495；相关峰偏移均值为0 ms，能量时间重心变化均值约2.154 ms。见 [完整摘要](sources/remaining-modifications-20260912/temporal-live-2-audit.json)。这些是指定共同视图中的描述性变化，不是新候选评价、时间无失真认证或神经保护证明。
