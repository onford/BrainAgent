# 解读中的事实、限制和假设

指标解读现在必须区分测量描述、测量限制和待验证假设。假设同时记录前提、竞争解释与可检验预测，页面明确显示其待验证身份。模型声明的每一种推断依据，都要通过确定性可用性检查并引用对应证据。

单一候选/阶段解读不提供已核验的配对变化、神经真值或规范人群阈值，因此不能声明使用这些依据。数值秩、容差判定和平均秩不能作为严格零特征值的证明。总方差或带通设置不能作为频率主导的证据。

有完整、有限、非负 PSD 及严格递增频率轴时，程序从实际保存曲线计算最大频率格点、并列最大数、范围和梯形积分。只给数组范围、缺失频率轴或部分测量时，不生成频率事实。最大格点不等于生理振荡来源；总积分也不被称为独立神经保护指标。

原生 PSD 曲线先做通道中位数，再做 epoch 均值；μ/β 等标量则平均其有限度量值，二者不能当作同一条聚合曲线的均值或积分。这些归约合同现进入质量汇总和解读上下文，不改变已有计算值。旧产物未记录的归约方式不会凭空补成已核验事实。

新运行的解读检查其冻结知识修订。已停用或正文改动后等待执行绑定复核的来源，不能通过解释卡绕回新解读；历史运行仍按自己的冻结依据读取。相同内容的修订缓存继续校验，不修改旧输出。

真实验证使用第 7 轮已结束的冻结测量，在独立解释验证目录执行六次限额模型调用；未延续或重置原搜索预算，也未改变其结果。三项回复分别核对到总方差 5871.3959473383065 µV²、12 条记录的 `singular_covariance` 缺失原因及 PSD 最大格点 10.467289719626168 Hz。模型没有由总方差推出低频主导，也没有把记录到的数值奇异原因写成独立脑源判断。见 [原始回复审计](sources/remaining-modifications-20260912/metric-claims-live-1-audit.json)。

这三个回复来自同一模型的草拟与复核，不是独立专家确认。结构化依据检查不能证明所有自由文本都忠实：模型仍可能漏声明推断依据或错误理解来源。全任务的反事实语义样本、独立复核和对决策主链中全部解释的同等约束仍待完成。上述真实样本发生在归约提示与冻结来源过滤的最后补丁之前；这两项另有代码回归，不能宣称该样本已验证了后续所有修改。
