# 物理信号对照

质量评价保留原生测量视图，并为每条记录的每个阶段保存可核验的物理测量合同：原文件摘要、原始事件与窗口、通道和单位、采样率、参考及实际参考模型绑定、频率历史、执行单元/版本/参数。汇总仅保存合同摘要，完整内容位于对应质量明细。原生候选配对比较同时要求输入、面板、记录与试次分母一致；旧产物没有合同或合同不同则不生成差值。算子的展示名不能代替实际执行语义。

输出频带只沿实际输出的信号祖先推导。用于拟合的旁支滤波不会被算成最终信号的滤波。原生比较目前保守要求完整信号操作合同相同；因此某些实际可比但使用不同清理操作的候选也会被阻塞，需要另行声明共同对照。

对于有完整固定试次、相同原始采样网格的电极电压，新增三种只读分析产物：原始信号的共同视图、处理信号的共同视图、前两者的有符号差值。每个记录使用相同算法，不按被试选择配方，不拟合缩放、白化或时间偏移。先在同一通道集合分别做平均参考，再施加相同的四阶 Butterworth 零相位分析滤波；分析频带为固定工程范围 0.5–45 Hz 与双方声明频带的交集。该范围由合同决定，不根据数据或标签优化。

共同分析滤波不会撤销先前滤波的衰减，也不会让不同处理链具有相同总传递函数。差值包括滤波、参考、插值和清理的影响，不是纯伪迹、真实脑源或神经保留证明。采集滤波未知仍然是未知，名义频带不是校准的可用带宽。逐段零相位滤波的边缘效应保留，不拼接试次、不填补缺失分母。

三份完整 NPY 数组使用 V，并记录形状、试次身份和文件摘要。质量页面显示同一试次、同一通道的三个波形，共用纵轴，提供完整数组下载。分析覆盖数进入质量摘要，不参与候选评分。

裁剪拼接、实际重采样、时间映射未完全声明的原生整管线及缺失固定试次继续标为不可比；不能仅凭事件起点对齐就推断整段样本对应。RELAX/PREP/Automagic 的通用内部样本映射与频带适配仍需补齐，不能将当前实现称为所有原生流程的完整对照。

真实只读复核使用已结束第 7 轮的基础候选：12 条记录、180 个试次、每条 `15 × 64 × 321`。每份差值与保存的两个共同视图之差逐值一致（最大误差 0 V），原数据、历史元数据及分析源码不变。因为旧执行计划没有后来新增的可空知识字段，本次另建分析封套并记录唯一结构差异 `knowledge_revision: null`；没有重写原计划、执行结果或验收判定。见 [复核摘要](sources/remaining-modifications-20260912/physical-live-review-1-audit.json)。
