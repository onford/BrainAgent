# 已知源、记录模板与真实 EEG 的验证边界

现有真实 EEG 重建仍以 `real_eeg_cleanproxy` 标识。新增已知源验证使用独立的 `known_simulated_neural_signal` 合同；没有把真实 EEG 改名为纯净真值，也不把此验证并入 EEGNet 主分数。

固定四层球形导体、标准电极位置和三个指定位置/方向的偶极子生成电极电压。计算使用当前安装的 MNE 1.10.2 [球模型接口](https://mne.tools/1.10/generated/mne.make_sphere_model.html)与[偶极子前向接口](https://mne.tools/1.10/generated/mne.make_forward_dipole.html)。源位置、方向、导体参数、频率、相位、振幅、共同平均参考、源/电极数组和代码哈希均保存；没有对真实人或真实 EEG 做逆解、峰频拟合或个体参数拟合。

四个六秒场景分别降低源1、降低源2、增强两源和保持不变。10/20 Hz、2秒起点和幅度增益均为工程验证设计；源功率变化的解析值用于检查计算，不能作为人类 EEG 必须出现的形态。前向矩阵不代表真实个体解剖。

第二条轨迹使用实际记录的 EOG 波形。A01T.mat 与 [BNCI 提供方](https://bnci-horizon-2020.eu/database/data-sets)文件的全部 42806453 字节和 SHA256 一致。通道位置与单位还核对了 MOABB 的 BNCI 加载代码；[提供方说明](https://www.bbci.de/competition/IV/desc_2a.pdf)给出22 EEG、3 EOG和250 Hz采样。详见 [来源证明](sources/remaining-modifications-20260912/bnci-template-source-proof.json)。

模板固定取第三条无任务试次记录的 EOG1、10–34秒内四个连续六秒窗口，不按峰值或评价结果挑选窗口，不使用 MI 类别。原单位 µV 换算为 V，不重采样。一个固定工程空间权重把波形投影到模拟电极；它不是实际测得的眼动传导场。EOG可能含神经及其他成分，缺少逐眨眼真值标注，因此称为记录波形模板，不称为纯眼动真值。文件和派生数组保存在本地验证目录，源码仅跟踪程序与审计摘要。

当前验证矩阵包含五种工程污染及记录EOG模板、每种两档强度、四个源场景。对每个条件检查理想去除、恒等、零输出、0.1缩放、四样本循环错移，以及实际注册的1–40 Hz和1–8 Hz滤波。共84个“处理器×污染条件”结果，每个结果包含全部四个场景。理想去除使用注入真值，不能作为可部署方法；循环错移仅是负对照。

对照保持同一完整电压网格，直接比较 `P(x)` 与已知 `x`、`P(x+a)` 与 `P(x)`；不缩放输出以提高分数，也不把源中已知存在的10/20 Hz随窄带滤波一起从参考删除。完整六秒窗口保留滤波启动、结束和任务变换处效应，时间支持与局部误差仍需后续单独测量。

最终验证在固定源码中完成（7.781秒），全部产物验签，源文件及模板不变；117项相关回归通过。见 [验证摘要](sources/remaining-modifications-20260912/source-validation-3-audit.json)。在0.5强度工频条件下，1–40 Hz与1–8 Hz的残余RMS比约为0.189和0.153，源保留NRMSE却分别约0.229和0.959，说明残余较低可能同时伴随严重信号损伤。

运行方式（后端环境）：

```powershell
python -m app.search.source_validation <新的输出目录>
python -m app.search.source_validation <新的输出目录> --sfreq 250 --recorded-template <已验签模板.npy>
```

第二种方式要求同名JSON包含文件哈希、V单位、采样率、完整有序通道、原文件来源与固定样本选择。输出目录必须不存在；结果保存完整数组和清单。

这是两个滤波配置的有限数值验证。真实 EEG 的原有 cleanproxy 轨迹继续独立保留。更多头模型/源波形、独立标注的多类真实伪迹模板、完整原生方法、时间/频谱/侧化保护测量、全记录及独立数据验证仍未完成；三类证据不能合成“已证明真实神经信息无损”。
