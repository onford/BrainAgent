## 重新导出

在项目根目录、现有开发依赖和本地 API 可用时运行：

```powershell
node frontend/scripts/export-offline-workflow.mjs 3ac37f8b5b334d94a56a54eb052152b4
node frontend/scripts/verify-offline-workflow.mjs
```

导出器只读取已保存的运行及产物，不启动 Agent。省略运行 ID 时使用运行列表的第一条；第二个位置参数可指定输出 HTML 路径。生成过程核对内嵌产物的大小及 SHA-256，并将页面、样式和压缩内容封装进 HTML。

验证使用 jsdom 在禁止网络的环境中检查本地文件启动、内容哈希和阅读交互。它不代替浏览器的视觉排版检查。
